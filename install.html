Install on iPhone / iPad

  1. Open this page in Safari (not inside another app's browser).
  2. Tap the Share button at the bottom of the screen.
  3. Scroll down and tap Add to Home Screen, then Add.
  4. Launch it from your home screen — it opens full-screen and works offline.

Install on Android

  1. Tap Install app above, or open Chrome's ⋮ menu.
  2. Choose Install app / Add to Home screen.
  3. Launch it from your home screen.

Install on desktop

  1. Use the install icon in the address bar (Chrome / Edge), or the browser menu → Install.
